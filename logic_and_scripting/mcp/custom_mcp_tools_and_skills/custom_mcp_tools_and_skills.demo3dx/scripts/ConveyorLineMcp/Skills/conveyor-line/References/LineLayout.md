# Line Layout

All conveyors are `Uncontrolled Straight Belt` conveyors at rotation `(0, 0, 0)`, so each one extends in +X from its Start connector. The belt surface is at a height of 0.83 m.

| Conveyor | Start location | Length | Default speed | Feeds |
| --- | --- | --- | --- | --- |
| `CV_01` | `(0, 0.83, 0)` | 2 m | 0.5 m/s | `CV_02` |
| `CV_02` | `(2, 0.83, 0)` | 2 m | 0.5 m/s | `CV_03` |
| `CV_03` | `(4, 0.83, 0)` | 2 m | 0.5 m/s | End of line |
